How it works

A {{ total_people }}×{{ total_questions }} binary matrix, SVD, and a hard consistency mask.

The matrix

M is {{ total_people }}×{{ total_questions }}. Rows are classmates, columns are yes/no questions spanning region, appearance, personality, and habits.

M ∈ {0,1}^{{ '{' }}{{ total_people }}×{{ total_questions }}{{ '}' }}

SVD

M = UΣVᵀ via numpy.linalg.svd. Keeping k = {{ k_latent }} dimensions retains {{ cumulative_k_pct }}% of the variance. σ₁ ≈ {{ '%.2f'|format(sigma_display[0]) }} alone explains about {{ variance_sigma1_pct }}%.

The guess

Any candidate that contradicts an answered question has probability exactly 0. When exactly one candidate survives, the belief hits 1.0 and the game stops. Until then, the next question is picked by maximising binary entropy over the filtered belief.
